0总览
1厂商管理

背景

厂商管理当前缺少对场馆入场余额的限制能力。本次新增"入场余额限制"配置项：运营可针对每个场馆（厂商与游戏类型的组合，如某电子游戏厂商、某真人厂商）单独设置余额门槛，用户余额低于门槛时无法进入对应游戏，门槛为 0 表示不限制。同时为厂商管理补充操作留痕（记录最近一次操作人与操作时间），并明确前台侧余额不足时的提示方式与校验时机。

整体流程

运营配置余额门槛
→
用户点击进入游戏
→
系统校验余额
→
放行 / 拦截并提示
图：入场余额限制的整体业务流程

后台配置

场馆列表新增三列：入场余额限制、最后操作人、最后操作时间（橙色标记为本期新增）。点击表格中的余额数值可直接输入金额，点击对钩保存；原有编辑弹窗也可设置该值。两种方式使用相同的金额校验规则。

字段说明默认值配置效果
入场余额限制本期新增 进入对应场馆时，用户所需要的最低余额 0（不限制） 用户余额低于该值时无法进入游戏；允许最多 2 位小数；不允许负数；暂不设上限；适用于全部场馆类型（含未来新增类型）
最后操作人本期新增 该行任意配置项最近一次变更的操作账号 — 随任意字段修改自动更新
最后操作时间本期新增 该行任意配置项最近一次变更的时间 — 随任意字段修改自动更新

前台展示与交互

用户点击进入游戏时校验当前余额。余额充足时正常进入游戏；余额不足时拦截进入并弹出提示，用户保持在游戏大厅页面。

用户点击某个游戏，尝试进入
→
系统校验：当前余额是否 ≥ 该场馆配置的入场余额限制场馆配置为 0 时视为不限制，直接放行
余额 ≥ 门槛（含门槛为 0）→正常进入游戏，无额外提示
余额 < 门槛→拦截进入，弹出提示条，停留在游戏大厅
图：进入游戏时的余额校验流程

前台参考

点击放大 · 余额不足时页面上出现的提示条
点击放大 · 提示条局部
提示文案结构：Saldo insuficiente {金额}（葡语，意为"余额不足 {金额}"）。

{金额} 为变量，取值为该场馆当前配置的"入场余额限制"数值，非固定文案。参考截图中的 10,22 即对应场馆的配置金额（葡语数字以逗号作为小数点）。

触发条件与反馈

触发条件系统反馈
点击场馆列表中的入场余额限制数值当前数值切换为输入框，并显示对钩保存按钮；按 Esc 可取消本次编辑
输入合法金额后点击对钩保存该场馆的新限制金额，恢复数值展示，并更新最后操作人与最后操作时间
输入为空、负数、非数字或超过 2 位小数后点击对钩保持输入状态，显示校验提示，不保存原值
该场馆入场余额限制 = 0不限制，直接进入游戏，无提示
用户余额 ≥ 该场馆配置的入场余额限制直接进入游戏，无提示
用户余额 < 该场馆配置的入场余额限制拦截进入，弹出提示条"Saldo insuficiente {金额}"（金额=该场馆配置值），用户停留在游戏大厅原地

其他规则说明

规则项说明
权限管理入场余额限制配置纳入现有角色权限体系，按菜单/功能维度分配只读与编辑权限，不新增独立权限点
操作留痕仅保留最近一次操作人与操作时间，覆盖式记录，不保留完整变更历史
已在游戏中的用户入场余额限制仅在用户点击进入游戏时校验一次，配置变更不影响已在游戏中的用户
货币口径入场余额限制按系统默认货币计，本期不支持多币种配置
试玩/免登录模式不受入场余额限制约束，该限制仅作用于进入真实游戏环境
场馆维护/关闭状态配置保留不变，场馆重新开启后沿用原值，无需重新设置
批量设置本期不提供批量设置或导入，场馆需逐一配置
多语言前台提示文案需支持按当前语言环境切换，本期实现切换机制，各语言文案另行提供
