背景

总控「站点场馆管理」下只有「场馆配置总控」「游戏配置总控」两个平台级页面，不分站点：可维护 / 启用 / 停用场馆和游戏、手工改场馆热门游戏数量、批量修改有效注单，但不能按站点调整顺序。场馆置顶、热门置顶、场馆内置顶只在商户后台操作，总控要替站点调整只能登录商户后台或提工单。

另外：总控停用的游戏、场馆仍下发到站点，会出现在站点排序列表里，已置顶的没有处理规则；同一款游戏的原厂版与 MY 版在前台同时出现、位置不同。

本期做三件事：站点选择（现网两页选站点后显示该站点数据）；置顶移到总控（场馆置顶、热门置顶、场馆内置顶都能在总控按站点操作，与商户后台同一份数据）；原厂 / MY 切换由总控控制。同时处理总控停用过滤。商户后台不改。

需求说明

需求点位置说明
1. 站点选择本期新增场馆配置总控、游戏配置总控搜索区新增「站点」（必选）。进入页面不加载数据，选站点并查询后显示该站点的场馆 / 游戏，并追加该站点的列（H5展示顺序、站点状态、置顶、关联、前台显示等）。现网的列与平台级操作（维护 / 启用 / 停用、批量修改有效注单、游戏「排序」）保留，仍对全平台生效。场馆「编辑排序数值」删除，热门游戏数量改为显示该站点的值、只读
2. 置顶移到总控本期修改场馆配置总控、场馆游戏排序弹窗、热门游戏排序（新增菜单）商户后台的三类置顶都能在总控按站点操作：场馆置顶（场馆配置总控）、场馆内置顶（场馆配置总控 → 场馆游戏排序）、热门置顶（新增菜单「热门游戏排序」）。规则与商户后台一致：位置从 1 连续、新置顶放末尾、改位置为插入、取消后前移、批量置顶 / 取消、位置快速筛选；与该站点商户后台同一份数据，任一端修改另一端可见
3. 原厂 / MY 切换由总控控制本期新增场馆配置总控、游戏配置总控按站点选择游戏对在前台显示原厂版还是 MY 版，默认 MY：场馆配置总控「原厂 / MY 切换」按场馆对一键切换，「关联场馆」点击「N 个游戏对」可查看该场馆对的游戏对并逐个切换；游戏配置总控新增关联（显示对方游戏）、前台显示列与筛选，单个「切换」与批量切换。前台同一游戏对只显示一款；目标版本已被总控停用时不能切换
4. 总控停用过滤本期修改场馆配置总控、游戏配置总控的「停用」停用的场馆 / 游戏，各站点前台与热门游戏排序、场馆游戏排序列表都不再显示；已置顶的自动取消，其后前移；停用当下生效
不在本期—排序（场馆或游戏的排序数字）待讨论后另行确定；商户后台本期不改

总控停用过滤

项目规则
范围本期修改停用的场馆、停用的游戏（含停用场馆下的全部游戏）：各站点前台不显示；总控与商户后台的热门游戏排序、场馆游戏排序列表不显示；不计入场馆热门游戏数量。由下发数据统一过滤，商户后台页面不改
已置顶的处理停用的游戏：各站点的热门置顶、场馆内置顶自动取消，其后前移；停用的场馆：各站点的场馆置顶自动取消，其后前移。重新启用后回到自动排序区
生效时间停用当下生效（下发数据立即过滤，前台展示更新按现网缓存）；不需要站点点「对齐平台排序」
游戏对当前显示的版本被停用：前台不显示该游戏对，不自动换版本；目标版本已被停用：不能切换
总控维护沿用现网：前台照常显示，标「维护中」
后台两页场馆配置总控、游戏配置总控照常列出停用的场馆 / 游戏（便于启用）；这些行 H5展示顺序、热门排名显示「-」，不可置顶

功能点清单

  1. F1【P0】站点选择：两页站点必选，进入不加载数据；平台级状态操作保留；删除热门游戏数量手工编辑。
  2. F2【P0】场馆置顶移到总控：新规则、批量、位置筛选，按站点。
  3. F3【P0】热门置顶移到总控：新菜单热门游戏排序，按站点。
  4. F4【P0】场馆内置顶移到总控：场馆游戏排序弹窗，按站点。
  5. F5【P0】原厂 / MY 切换由总控控制：场馆配置总控按场馆对一键、游戏配置总控单个与批量；前台只显示当前版本；目标版本停用不能切。
  6. F6【P0】总控停用过滤：前台与排序列表不显示，置顶自动取消，当下生效。
  7. F7【P1】展示：站点状态、关联场馆、关联、前台显示列与筛选、热门排名、置顶数量提示。
  8. F8【P1】上线数据处理：已有置顶保留；已停用的置顶取消；显示版本为 MY。

开发测试重点说明

  1. 站点必选：进入不加载数据，选站点查询后显示该站点数据；平台级操作在站点视图中仍对全平台生效。
  2. 按站点的数据：所有接口带站点参数，取已查询站点；验证时检查其他站点未被改动。
  3. 三类置顶与商户后台同一份数据：位置任何时候 1 到 N 连续；新增 = N+1；取消 = 其后 −1；修改 = 插入。
  4. 三类队列互相独立：筛选不影响位置计算。
  5. 游戏对置顶按版本：前台只取当前版本，隐藏版本不占位；切换不改置顶；目标版本停用不能切。
  6. 总控停用过滤：下发数据统一过滤，前台与两类排序列表不显示，置顶取消，当下生效；维护沿用现网。
  7. 前台缓存：沿用现网，本需求不提刷新要求。
  8. 待开发确认：场馆手工热门游戏数量删除前，确认没有其他地方在用。
  9. 后续：排序待需求方讨论后另行确定；商户后台是否做切换下期再定。
